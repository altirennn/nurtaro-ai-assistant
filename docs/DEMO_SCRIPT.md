# Двухминутная демонстрация работодателю

**0:00–0:20 — проблема и ограничения.** «Это независимый демонстрационный проект для двуязычного ассистента родителей детей 0–3 лет. В базе только синтетические инструкции для игр; это не материалы и не одобрение Nurtaro. Ассистент не ставит диагнозы и воздерживается без источника».

**0:20–0:45 — API и профиль.** Откройте Swagger по `http://localhost:8000/docs`. Через `POST /profiles` создайте профиль на 18 месяцев с языком `kk`, интересом «кітап» и материалом «кітап». Покажите `GET /profiles/{id}`.

**0:45–1:15 — RU/KZ RAG.** В `POST /chat` спросите по-русски: «Как подготовить игру с кубиками?» Затем: «Текшемен ойынды қалай дайындауға болады?» Покажите язык, источник и chunk ID. Уточните, что локальный fallback векторизует слова и символьные n-граммы, а качество сравнивается с модельным embedding только после отдельного прогона.

**1:15–1:35 — abstention и загрузка.** Спросите «Какой сегодня курс евро к тенге?» — ответ должен признать отсутствие данных. Затем загрузите TXT/Markdown через `POST /documents/upload`, вызовите `POST /documents/index` и задайте вопрос по новому материалу.

**1:35–1:50 — видео.** Если установлены CV-зависимости и модельные веса, загрузите короткий лицензированный ролик через `/vision/analyze` и покажите timestamped YOLO-детекции. Затем загрузите VTT/SRT транскрипт через `/videos/transcripts/upload`, задайте вопрос через `/chat` и покажите источник с временной меткой. Назовите это переносимым демо для video pipeline, а не продуктом закрытого стартапа.

**1:50–2:00 — инженерная зрелость.** Покажите `/health`, результаты evaluation, Docker Compose и QLoRA отчёт в `EXPERIMENTS.md`. Скажите прямо: «Я запустил QLoRA на RTX 3050 и сравнил base с adapter. На 8 синтетических кейсах выбранные прокси не улучшились, а казахские ответы и отказ на медицинском вопросе оказались плохими; поэтому этот adapter нельзя считать готовой моделью. Для CV есть video inference endpoint, но целевой набор не размечен и метрики не измерялись».

Перед публичным показом не используйте реальные данные детей или частное видео. Установите `requirements-vision.txt` и заранее скачайте/проверьте модельные веса. При включении локальной Qwen заранее запустите Ollama, скачайте выбранную модель и укажите `LLM_PROVIDER=ollama`.
