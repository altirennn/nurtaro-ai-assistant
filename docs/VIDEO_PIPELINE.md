# Видео pipeline: CV и поиск по видеоурокам

Это независимая демонстрация transferable навыков для требования CV/video. Второй стартап AMM Ventures закрыт, поэтому проект не приписывает ему конкретный сценарий.

## 1. YOLO-анализ короткого ролика

API принимает MP4/MOV/MKV/WEBM/AVI с API-ключом. Временные ограничения задаются через `.env`:

| Параметр | По умолчанию | Верхняя граница |
|---|---:|---:|
| Размер файла | 50 MiB | 200 MiB |
| Длительность | 30 секунд | 300 секунд |
| Интервал кадров | 1 секунда | 10 секунд |
| Число кадров | 30 | 120 |
| Длинная сторона кадра | 1920 px | 4096 px |
| Модель | `yolo11n.pt` | cache name или локальный `.pt` |
| Порог confidence | 0.35 | 0.95 |

Установите optional runtime. Для GPU сначала выберите PyTorch wheel, совместимый с вашей CUDA:

```powershell
python -m pip install -r requirements-vision.txt
```

```powershell
curl.exe -H "X-API-Key: your-demo-key" -F "file=@C:\temp\licensed-demo.mp4" http://localhost:8000/vision/analyze
```

Ответ содержит исходную длительность, FPS, размер, число выбранных кадров, классы, confidence, bounding box координаты исходного кадра и время inference. `detection_counts_by_class` считает появления на выбранных кадрах, а не уникальные объекты. Исходный файл записывается во временную директорию и удаляется после анализа; кадры и кропы не сохраняются.

`yolo11n.pt` — предобученный детектор общих классов, не модель развития ребёнка и не fine-tuning под методику/игрушки Nurtaro. Метрики по целевым классам пока не измерялись.

## 2. Индексация видеоурока в RAG

Распознавание речи не реализовано. Загрузите собственный UTF-8 TXT, VTT или SRT, полученный из разрешённой расшифровки:

```powershell
curl.exe -H "X-API-Key: your-demo-key" -F "file=@C:\temp\lesson.vtt" "http://localhost:8000/videos/transcripts/upload?language=ru"
```

API сохраняет очищенный транскрипт как owner-scoped документ, нормализует временные метки и сразу индексирует текущим RAG embedding backend. Исходный файл субтитров не сохраняется. Обычный `/chat` ищет по транскрипту и возвращает ссылку на документ/chunk; timestamp остаётся в сниппете.

## Протокол оценки

Модельные метрики сейчас помечены как **not measured**. Чтобы получить результат для сравнения:

1. Выбрать публичный датасет или собственный набор с явной лицензией и без персональных/детских видео.
2. Зафиксировать целевые классы, разметку и разделение train/validation/test по роликам, а не по кадрам одного ролика.
3. Зафиксировать commit, версии Ultralytics/PyTorch, вес, устройство, размер кадра, sampling и confidence threshold.
4. На holdout посчитать precision, recall и mAP50–95 по кадрам; отдельно измерить runtime и peak VRAM на названном оборудовании.
5. Проверить ошибки на полных роликах: повторные детекции между кадрами, пропущенные события, decoding и RAG по субтитрам.

Модуль не делает tracking, поэтому IDF1/HOTA не заявляются. Перед коммерческим использованием Ultralytics проверьте актуальные условия AGPL-3.0/Enterprise и совместимость с распространением.
